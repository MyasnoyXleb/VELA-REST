# VELA — Mediterranean Fine Dining

An original luxury restaurant landing-page concept built with plain HTML, CSS and JavaScript. Fictional brand and sample restaurant details, created as a portfolio project.

## Run locally

Open `index.html` in a browser, or use VS Code with Live Server for a more convenient development loop.

## Features

- Editorial luxury visual direction: warm ivory, charcoal, muted brass and display serif typography
- Full-bleed hero, philosophy, menu preview, atmospheric quote, gallery, reservation form and footer
- Responsive layout and mobile navigation
- IntersectionObserver reveal animations
- Accessible labels, keyboard-friendly native form controls, reduced-motion support
- Reservation form demo with client-side feedback; it does not send or store bookings

## Assets

Fonts load from Google Fonts. Photography loads from Unsplash URLs, so an internet connection is required for those assets. Replace image URLs and fictional contact/location details before presenting this as a real client project.

## Portfolio note

VELA is a fictional concept. Present it as a self-initiated design and frontend exercise, not a commissioned restaurant website. The layout and copy are original; the design takes broad inspiration from luxury hospitality/editorial web design rather than reproducing a specific site.
