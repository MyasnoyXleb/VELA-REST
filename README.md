# VELA — меню ресторана

Концептуальный сайт меню премиального ресторана на чистых HTML, CSS и JavaScript.

## Структура
- `index.html` — шапка с названием ресторана, меню и футер с контактной информацией.
- `style.css` — адаптивная редакционная стилистика: тёмный фон, тёплая типографика и латунные акценты.
- `script.js` — небольшой JavaScript-файл для дальнейшего расширения взаимодействий.

## Запуск
Откройте `index.html` в браузере или используйте расширение Live Server в VS Code.

Фотографии и шрифты загружаются из интернета. Название, контактные данные, блюда и цены вымышлены и приведены для демонстрации концепта; это не реальное меню ресторана.
